# Prompts to Build This Project

The exact prompts used to build this project from scratch with AI. Concise by design — the less you over-specify, the more AI can make sensible decisions.

---

## 1. Initial Project Generation

> Build a Spring Boot 4 / Java 21 event-driven app called `kafka-ai`.
> - REST API with CRUD for `Employee` and `Department`
> - PostgreSQL as the write database (JPA/Hibernate)
> - Kafka producer that fires an Avro event on every employee create, update, delete
> - Kafka consumer that saves each event as a document in MongoDB
> - Avro schema with logical types: decimal for salary, date for hire date, nested department record, EventType enum
> - MapStruct to map Employee entity → Avro EmployeeEvent
> - Swagger/OpenAPI docs
> - Docker Compose with Postgres, Kafka, Schema Registry, MongoDB, Control Center
> - Lombok throughout

## Tips for Reproducing This

- **State the stack upfront** — versions matter (Spring Boot 4, Java 21, Kafka 7.6.1)
- **Describe intent, not implementation** — say "fire a Kafka event on every employee change", not "create a KafkaTemplate bean and call send()"
- **One concern per prompt** — don't bundle unrelated changes in one message
- **Let AI audit** — asking "does this follow best practices?" catches more bugs than manual review
- **Make architectural decisions yourself** — tell AI *what* to build, let it decide *how*
- **Short commands work** — "remove the tests" is enough; AI reads the context
